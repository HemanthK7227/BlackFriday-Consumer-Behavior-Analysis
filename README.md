# BlackFriday-Consumer-Behavior-Analysis
This project analyzes consumer purchasing behavior during Black Friday using real-world sales data. Using Tableau and Excel, we explored how demographics like age, gender, occupation, and city category influence buying patterns. 

Key findings include:
- Age group 25–35 has the highest purchase volume.
- Males make more transactions than females.
- Electronics top the product category sales, followed by clothing.
- City Category B and newer city residents (≤1 year) spend significantly more.

📊 Dashboards were created to help retailers tailor promotions and improve marketing strategies using data-driven insights.

## Tools & Technologies
- Tableau
- Microsoft Excel
- Kaggle Dataset: [Black Friday Sales Data](https://www.kaggle.com/datasets/rajeshrampure/black-friday-sale)
